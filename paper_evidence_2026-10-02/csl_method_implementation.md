# CSL-YOLO26候选方法实现记录

## 1. 证据驱动的替换关系

阶段9已经证明统一细长目标增权不能稳定改善馈线类，阶段10则显示RRU侧馈线和馈线剪断缺陷的错误样本存在小尺度偏置。当前实现因此删除细长目标权重分支，改为与三类困难机制逐一对应的训练组件。

| 困难机制       | 实现组件                       | 作用位置        |         推理开销 |
| -------------- | ------------------------------ | --------------- | ---------------: |
| 遮挡和背景相似 | P3—P4语义`ContextGate`及框监督 | 颈部P3输入      | 有，单个轻量门控 |
| 小尺度定位不稳 | 尺度自适应IoU—NWD定位          | 正样本框回归    |               无 |
| 类别外观相近   | 最难负类间隔约束               | 正样本分类logit |               无 |

## 2. 尺度自适应IoU—NWD定位

对目标框在输入图像像素坐标下计算归一化平方根面积`s=sqrt(wh/(WH))`。当`s`小于阈值`s0`时，使用`alpha=gain*clip((s0-s)/s0, 0, 1)`在CIoU损失与NWD损失之间连续插值；大于阈值时保持原CIoU。当前预注册筛选值为`gain=0.5`、`s0=0.04`、NWD常数`C=12.8`。该设计不改变正样本分配、DFL/L1分支或推理网络。

## 3. 最难负类间隔约束

对每个任务对齐分配得到的正样本，取匹配类别logit和其余类别中的最大logit。若两者间隔小于0.2，则产生hinge损失，并按匹配质量加权。当前预注册增益为0.1。该约束不假设固定混淆类别；最终是否改善相似类别必须由混淆矩阵和逐类AP验证。

## 4. 上下文门控与框监督

`ContextGate`接收P3细粒度特征和P4语义特征。P4先经1×1卷积对齐通道并上采样，再与P3拼接生成单通道空间门控；输出为`P3*(0.5+sigmoid(gate))`。门控卷积的权重和偏置均初始化为0，因此新模型加载基线权重后的初始映射严格等于原P3。

训练时根据现有归一化边界框在门控分辨率上生成二值前景掩码，并用带上限的正样本权重计算BCE监督。该监督没有增加像素级人工标注。为避免把带计算图张量留在模块状态中，只有损失函数启用监督后才捕获门控logit，并在构造损失后立即释放。

## 5. 公平筛选矩阵

| 预设                | ContextGate | NWD | 类别间隔 | 用途             |
| ------------------- | ----------: | --: | -------: | ---------------- |
| `paper_csl_control` |           0 |   0 |        0 | 同预算控制组     |
| `paper_csl_nwd`     |           0 |   1 |        0 | 小尺度定位单因素 |
| `paper_csl_margin`  |           0 |   0 |        1 | 类别边界单因素   |
| `paper_csl_context` |           1 |   0 |        0 | 复杂背景单因素   |
| `paper_csl_losses`  |           0 |   1 |        1 | 两项训练损失组合 |
| `paper_csl_full`    |           1 |   1 |        1 | 完整候选模型     |

所有组必须使用相同v9权重、基础数据、`seed=0`、输入尺度、优化器、增强、训练上限和早停规则。筛选阶段不得访问535张内部测试集；只有开发验证集通过预注册门槛的配置才进入多种子和冻结测试。
