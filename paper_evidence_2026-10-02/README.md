## 2. 当前模型开发数据视图

| 分区   | 图像数 | 实例数 |
| ------ | -----: | -----: |
| 训练集 |  3,529 |  6,822 |
| 验证集 |    500 |  1,980 |

训练集由原训练图像、馈线剪断缺陷上下文裁剪图像和天线侧馈线上下文裁剪图像共同组成。因此，该数据视图不等同于原始语料的 2,724/303/535 图像划分；论文中必须分别报告“原始数据集规模”和“模型实际看到的开发数据视图”。

## 3. 自动审计结果

- 未发现缺失标签、非法类别编号、非法归一化坐标或越界标注框。
- 基于文件名中源图哈希的同源标识检查未发现训练、验证和测试分区间重叠。
- 基于解码后像素的 SHA-256 检查未发现跨分区完全重复图像。
- 保守的感知哈希与缩略图差异筛查发现 1 组训练—验证近重复候选。

部分训练裁剪文件名包含 `base_test` 字样，但源图哈希与当前验证集、测试集均无重叠。该字样反映早期数据处理阶段的命名来源，不能单独作为当前分区泄漏的证据；正式归档时仍应改用不含历史分区语义的不可变样本标识。

## 4. 人工复核结论

近重复候选由以下两幅图像组成：

- 训练集：`v8_train__base_train_7e1a901343b0f1f0b155.jpg`
- 验证集：`v8_train__base_train_3f35df777145c6bc391c.jpg`

两幅图像的 SHA-256 不同，分辨率和裁剪范围也不同，但人工目视确认其展示同一射频拉远单元及同一周边现场，属于同场景不同取景。该结果表明，文件级和源图级去重不足以保证站点/设备实体独立。

## 5. 对论文主张的约束

1. 当前验证结果只能表述为既定开发划分下的性能，不应表述为跨站点泛化能力。
2. 在完成建筑、站点或设备实体分组划分前，不使用验证集结果支撑“现场泛化”“鲁棒部署”等强主张。
3. 现有 535 图像测试集已参与多轮方案核验，继续保留为内部测试集；最终论文需要新增一次性冻结、未参与选择的站点级外部测试集。
4. 后续训练、消融和比较实验必须保存数据清单、随机种子、权重哈希和机器可读指标。

## 6. 已锁定的正式类别名称

| 原标签           | 中文正式名称 |
| ---------------- | ------------ |
| `coupler`        | 耦合器       |
| `antenna_s`      | 小型天线     |
| `RRU`            | 射频拉远单元 |
| `Feeder_RRU`     | RRU侧馈线    |
| `antenna_b`      | 射灯天线     |
| `cut`            | 馈线剪断缺陷 |
| `Feeder_antenna` | 天线侧馈线   |
| `POWER`          | RRU电源模块  |
| `BOX`            | 分纤箱       |

`Feeder_RRU`和`Feeder_antenna`按空间位置定义：靠近射频拉远单元的一段为RRU侧馈线，靠近射灯天线的一段为天线侧馈线。

现有专家数据中的752张负样本由类别规则和固定随机种子选出：图像不含`cut`或`Feeder_antenna`，但含`antenna_s`、`Feeder_RRU`或`antenna_b`。因此本文将其准确称为“易混淆背景负样本”，不表述为由模型误检挖掘得到的困难负样本。

## 7. 融合参数敏感性结论

已完成21组开发验证设置及2组同协议内部测试核验。验证集上选择的权重2.5、NMS IoU=0.6折中点未能在内部测试集复现增益：相对无专家基线，mAP@0.5下降0.00059，mAP@0.5:0.95下降0.00115，馈线剪断缺陷和天线侧馈线的AP@0.5:0.95也分别下降0.00752和0.00285。该结果按负结果保留，当前不主张较高专家权重具有稳定泛化收益。详见`fusion_sensitivity_summary.md`。

## 8. 专家训练初始化的复现风险

历史`v14`训练参数显示，预设从早期配置继承了`yolo26s_v8_dataset9_relabel_ft/weights/best.pt`作为二次初始化权重；该文件当前不存在，最佳实验包也未归档其哈希或副本，因此旧专家训练无法做到逐位重放。新的四组数据策略消融统一删除这一失效继承覆盖，直接从仍存在且已记录SHA-256的`yolo26s_v9_trainval_o2m_dfl15_ft/weights/best.pt`开始训练。新消融只在四组之间作公平比较，不与旧专家训练结果混作随机种子重复。

## 9. 专家数据策略消融结论

四组公平训练与统一复评表明：易混淆背景负样本使验证集 mAP@0.5:0.95 从 0.6135 提高到 0.6218，但内部测试集从 0.4698 微降到 0.4697；上下文裁剪使验证集和内部测试集 mAP@0.5:0.95 分别下降 0.00828 和 0.00087。同时加入两类数据时，内部测试集 mAP@0.5 虽提高 0.00619，mAP@0.5:0.95 却下降 0.00224。现有单随机种子证据不支持把上下文裁剪或易混淆背景负样本表述为稳定提高泛化性能的核心创新。完整表格与证据边界见`specialist_data_ablation_summary.md`。

## 10. 图像级关系校准结论

按验证集选择的关系校准强度0.25在内部测试上仅使总体mAP@0.5:0.95提高0.00003，同时mAP@0.5下降0.00007、Recall下降0.00833；天线侧馈线AP@0.5:0.95提高0.00382，RRU侧馈线下降0.00353。该方法主要在两类馈线间转移错误，已淘汰为论文主方法。后续若继续关系建模，必须把具体馈线候选与空间端点绑定，并在包含多类端设备的站点级样本上验证。详见`feeder_relation_summary.md`。

## 11. 紧裁剪—上下文裁剪对照结论

在同一初始化、参数和随机种子下，上下文裁剪相对紧目标裁剪使验证/内部测试mAP@0.5:0.95分别提高0.01329/0.02189，支持“局部放大时应保留连接语境”。但上下文裁剪相对仅完整正样本仍分别下降0.00828/0.00087，因此不主张上下文增强本身无条件提高性能。详见`tight_context_ablation_summary.md`。

## 12. 候选级空间关系校准结论

按验证集选定的候选级空间校准强度0.3使验证总体mAP@0.5:0.95提高0.00102，两类馈线AP@0.5:0.95分别提高0.00484和0.00434；冻结后，内部测试总体mAP@0.5:0.95反而下降0.00195，两类馈线AP@0.5:0.95分别下降0.01026和0.00731。该方案未形成跨划分稳定收益，已从主方法候选中淘汰。详见`feeder_spatial_relation_summary.md`。

## 13. 目标几何审计结论

在1280输入尺度下，馈线剪断缺陷短边中位数在train/val/internal test中分别约177/162/190 px，`<32²`面积占比仅约1%/1%/3%；天线侧馈线的主要几何特征是细长性，长宽比≥4的比例约18%/24%/27%。因此下一阶段不把P2小目标头作为主创新，而优先检验细长结构定位假设。详见`object_geometry_summary.md`。

## 14. 归一化细长目标定位损失结论

细长定位损失在500张验证集上使总体mAP@0.5:0.95提高0.00275，但预设目标类天线侧馈线下降0.00274；冻结后内部测试总体mAP@0.5:0.95下降0.00369，天线侧馈线和馈线剪断缺陷也分别下降0.00095和0.00637。该方案未形成机制一致或跨划分稳定收益，已淘汰。详见`elongation_loss_summary.md`。

## 15. 弱类错误分组结论

500张开发验证图像中的弱类错误以漏检和定位不准为主，而非类别互相混淆。RRU侧馈线和馈线剪断缺陷的错误目标短边中位数均约78 px，分别显著低于各自全部目标约165 px和136 px；天线侧馈线的错误却不集中在细长实例上。绝大多数馈线错误图像中对应端设备仍然可见，因而端点缺失、统一细长增权和简单关系重标都不是主要解释。下一阶段将已有P2结构作为高分辨率强基线，同时先核查馈线边界标注一致性。详见`weak_class_error_analysis.md`。

## 16. P2高分辨率强基线结论

YOLO26s-P2在完全一致的单随机种子协议下完成15轮训练。500张开发验证集上，总体mAP@0.5:0.95从控制组0.64425下降至0.59218，RRU侧馈线、馈线剪断缺陷和天线侧馈线分别下降0.02778、0.13207和0.09879；推理时间与GFLOPs均增加约62%。P2没有改善小尺度失败子集，已淘汰且未访问内部测试集。详见`p2_ablation_summary.md`。

## 17. OOF标注质量与数据继承结论

历史三折OOF流程对3,027张开发图像执行折外推理，从263张错误候选图像中定向选择200张、229条记录人工复核。规范化结果包含78条标注错误，最终形成75项有意义的标签修订，涉及73个文件。该样本由模型错误定向抽取，不能据此估计全数据集标注错误率。

逐文件语义审计发现，当前主实验`v13`只包含5个等价修订文件，另有68个文件仍保持OOF复核前状态；其中50个位于训练集、18个位于验证集。因此，历史`v15`清洗不能直接作为当前模型的数据质量贡献。下一阶段先合并这条修订链，再在同一清洁验证集上比较训练标签清洗的单因素效果。历史复核也没有提供独立边界重绘或双标注者一致性，论文不得声称边界框一致性已经得到证明。详见`annotation_quality_audit.md`。

## 18. OOF训练标签合并对照结论

在训练图像、验证标签、初始化、超参数和随机种子一致的单因素对照中，未合并OOF修订和合并修订的验证mAP@0.5:0.95分别为0.70459和0.70322。单种子差值为-0.00137，不支持把标签修订写成精度创新；OOF流程仅作为错误归因与数据版本追溯机制保留。处理组完整机器可读训练目录未进入本工作树，后续不得补造逐类指标。

## 19. CSL-YOLO26候选方法实现状态

已用三个可独立关闭的训练组件替换失败的细长目标增权路线：P3—P4语义上下文门控及框监督、尺度自适应IoU—NWD定位、最难负类间隔约束。新增结构从恒等映射初始化，两个损失分支在默认增益0时不参与计算，保证公平控制。14项专项测试及CUDA端到端训练烟雾测试通过；当前尚无正式精度结果，不能在论文中填写提升幅度。详见`csl_method_implementation.md`。
