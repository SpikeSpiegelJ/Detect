# 最佳实验结果论文材料包

本材料包只以独立 test 集上表现最好的实验作为主结果：YOLO26s 与 YOLO26m 通用检测器的 TTA 集成，加上面向 `cut` 和 `Feeder_antenna` 的二类专家检测器，在预测张量层完成类别映射和融合后统一执行 NMS。

## 最佳结果

- 独立 test：535 张图像，1178 个目标实例。
- Precision：0.855。
- Recall：0.840。
- mAP50：0.8841。
- mAP50-95：0.5202。
- 推理设置：1280 像素、batch=2、通用模型 TTA、专家模型单尺度、NMS IoU=0.50、专家权重 1.0。
- 测试硬件：NVIDIA GeForce RTX 3060 12 GB。

## 文件说明

- `论文实验结果与创新点.md`：可直接用于撰写论文实验部分的中文材料。
- `实验思路与模型工作机制.md`：说明研究问题、实验路线、三个检测分支、数据构造和预测融合过程。
- `tables/最佳实验结果汇总.xlsx`：可编辑的论文数据表，包含主结果、逐类结果、消融结果和实验协议。
- `tables/*.csv`：所有表格的机器可读版本。
- `figures/Fig*.png`：600 DPI 位图，适合 Word 排版。
- `figures/Fig*.pdf`：对应的矢量图，适合 LaTeX 或期刊排版。
- `figures/BestFusion_*.png`：Ultralytics 对最佳融合方案生成的原始 PR、F1、P、R 曲线及混淆矩阵。
- `source_records/`：训练参数、数据清单、标注审核记录和验证代码快照。
- `reproducibility/复现实验命令.md`：复现最佳 test 结果的命令和模型路径。

## 结果使用边界

0.8841 是目前可报告的最高独立 test mAP50，尚未达到 0.900。开发验证集的 0.9508 只用于消融与模型选择，不能替代独立 test 结果。当前结果来自单次固定划分评估，没有重复训练的均值、标准差或置信区间，因此论文中不得使用“显著提升”这一统计表述。
