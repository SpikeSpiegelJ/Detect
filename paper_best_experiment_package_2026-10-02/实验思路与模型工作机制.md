# 实验思路与模型工作机制

## 1. 研究问题

本实验面向通信基站图像中的九类设备及连接部件检测。早期通用检测模型在 RRU、antenna_b、BOX 等外观稳定、目标边界清晰的类别上已经取得较高精度，但在 `cut`、`Feeder_antenna` 和 `Feeder_RRU` 上持续出现漏检、类别混淆和定位偏差。这几类目标通常具有细长结构，局部纹理相似，其类别含义还与连接对象、端点位置和周围设备有关。因此，继续统一增强全部类别或单纯增大模型规模，难以针对性解决弱类别问题。

实验的基本假设是：通用模型负责学习完整场景和全部九类目标，弱类别专家模型集中学习 `cut` 与 `Feeder_antenna` 的细粒度差异，再在预测阶段将两者的候选框统一融合。这样既保留通用模型对其他七类目标的检测能力，又利用专家模型补充弱类别判别信息。

## 2. 整体实验路线

### 2.1 建立通用检测基线

首先在九类数据集上分别训练 YOLO26s 和 YOLO26m。两个模型均采用 1280 像素输入和 one-to-many 检测头。YOLO26s 具有较低计算成本，YOLO26m 具有更强的特征表达能力。推理时对两者执行测试时增强，将不同尺度和翻转视角产生的候选框合并，以降低单模型偶然漏检。

### 2.2 定位弱类别错误

根据验证结果和错误审核，统计 false positive、missed ground truth、class confusion 和 localization 等错误类型。实验发现主要问题集中在以下关系：

- `cut` 与 `Feeder_antenna` 互相混淆；
- `Feeder_antenna` 与 `Feeder_RRU` 混淆；
- 小尺度或被遮挡的细长馈线部件容易漏检；
- 只观察目标局部时，模型难以判断馈线连接到 RRU 还是天线。

这些结果说明弱类别需要连接上下文，而不仅是更强的整图颜色或旋转增强。

### 2.3 构建二类专家数据集

专家模型仅保留 `cut` 和 `Feeder_antenna` 两个输出类别。训练数据包含三部分：

1. 1002 张包含弱类别的完整训练图像，用于保留真实场景结构；
2. 1002 张围绕弱类别目标生成的上下文裁剪图，用于放大目标，同时保留连接端点和周围设备；
3. 752 张易混淆负样本，来源于包含 `antenna_s`、`Feeder_RRU` 或 `antenna_b`，但不包含 `cut` 和 `Feeder_antenna` 的图像。

负样本数量约为正样本数量的 0.75 倍，使专家模型不仅学习“目标长什么样”，还学习“哪些相似结构不属于目标类别”。人工审核进一步检查了 61 个错误候选，确认并修正 14 个标注错误，其中包含 9 个缺失框和 5 个已有标注修正。

### 2.4 训练弱类别专家模型

专家分支采用 YOLO26s，并从已有通用 YOLO26s 权重初始化。训练时将九类标签中的 `cut` 和 `Feeder_antenna` 映射为二类标签，忽略其他类别的正样本标注。模型因此将主要容量用于学习两类弱目标的形态、尺度和连接上下文。专家模型推理采用单尺度，以限制融合系统的额外计算开销。

### 2.5 预测级融合

最终系统对同一张输入图像并行执行三个分支：

1. YOLO26s 通用分支：输出九类 TTA 候选框；
2. YOLO26m 通用分支：输出九类 TTA 候选框；
3. YOLO26s 专家分支：输出 `cut` 和 `Feeder_antenna` 的单尺度候选框。

两个通用分支的预测首先拼接。专家预测随后建立一个九类得分张量，将专家类别 0 映射到通用类别 `cut`，将专家类别 1 映射到通用类别 `Feeder_antenna`，其余七类得分保持为零。映射后的专家候选框与通用候选框继续拼接，最后统一执行 IoU=0.50 的类别感知 NMS。该过程发生在 NMS 之前，因此通用分支和专家分支对同一目标的候选框能够直接竞争并去重。

## 3. 模型具体完成的工作

从功能上看，最终模型完成以下六项工作：

1. 从 1280 像素输入图像中提取多尺度视觉特征；
2. 使用 YOLO26s 和 YOLO26m 检测完整九类目标；
3. 通过 TTA 提高通用分支对尺度和视角变化的覆盖；
4. 使用二类专家模型重新检查 `cut` 与 `Feeder_antenna` 候选区域；
5. 将二类专家结果映射回九类标签空间，并与通用预测统一融合；
6. 通过类别感知 NMS 删除重复框，输出最终类别、置信度和边界框。

该系统不是串行的“先检测再分类”。三个检测器直接对整张图像并行推理，专家分支产生的候选框在后处理阶段与通用候选框共同参与筛选。

## 4. 各组件的作用

| 组件 | 主要作用 | 解决的问题 |
|---|---|---|
| YOLO26s 通用模型 | 提供稳定的九类基础检测 | 保持整体检测能力和较低模型偏差 |
| YOLO26m 通用模型 | 提供更强的特征表达和互补预测 | 降低单一模型的偶然漏检 |
| TTA | 从不同尺度和翻转视角产生候选框 | 提高对尺寸、方向变化的鲁棒性 |
| 二类专家模型 | 集中判别 cut 和 Feeder_antenna | 改善弱类别排序和局部定位 |
| 上下文裁剪 | 放大弱目标并保留连接关系 | 防止裁剪后丢失类别语义 |
| 困难负样本 | 提供结构相近但类别不同的样本 | 降低与 Feeder_RRU、antenna_b 等类别的混淆 |
| 类别映射 | 将二类专家分数投影到九类空间 | 使异构输出能够统一融合 |
| NMS 前融合 | 让所有分支候选框共同竞争 | 完成跨模型去重并保留高质量框 |

## 5. 实验验证逻辑

实验先在开发验证集上比较通用双模型集成与加入专家分支后的结果。专家分支使整体 mAP50 从 0.9487 提高到 0.9508，使 `cut` 的 mAP50-95 从 0.631 提高到 0.645，并使 `Feeder_antenna` 的 mAP50 和 mAP50-95 分别从 0.849、0.490 提高到 0.866、0.513。验证集结果支持专家分支确实对目标弱类别产生作用。

在冻结参数后，最终方案在独立 test 上取得 Precision=0.855、Recall=0.840、mAP50=0.8841 和 mAP50-95=0.5202。相较通用双模型集成，独立 test 的 mAP50 和 mAP50-95 均提高 0.0010。该增益表明融合方向有效，但幅度较小，说明弱类别的主要限制仍来自训练数据与 test 场景之间的分布差异。

## 6. 方法贡献与边界

本实验的核心贡献是围绕弱类别设计完整的“错误分析—上下文样本构造—困难负样本训练—专家预测融合”流程。其中最适合作为算法方法描述的是非对称通用—专家预测融合；上下文裁剪、困难负样本和人工审核属于支撑该方法的数据与训练策略。

该方案没有改变 YOLO26 的主干网络、颈部网络或检测头结构，也没有提出新的损失函数。论文中应避免写成“提出全新的目标检测网络”，更准确的表述是“提出一种面向连接关系敏感弱类别的通用—专家检测融合框架”。是否具有文献层面的首创性仍需通过相关工作检索确认。
